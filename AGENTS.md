# Home Layout Studio maintenance

Run `pkm status --current` before substantive edits. If this checkout is registered, follow its lease/task protocol. Never edit an active lease scope.

This repository contains generic code only. Keep all actual plans, photographs, dimensions, annotations, exports and conversation context outside the repository, including tests, screenshots, issue bodies and Git history. Use fabricated regression fixtures. Stage explicit paths, inspect `git diff --cached --stat`, and leave unrelated work untouched.

Run `npm test` before commit/push. Use a private `SENSITIVE_MARKERS` environment variable for household-specific publication checks; never commit its values. Enable the pre-push check with `git config core.hooksPath .githooks`. CI is a second check after publication and cannot prevent the first disclosure.

Serve only the repository root on loopback for browser checks. No dependency installation is required. Test private imports by selecting files from an external private directory; never copy them into a served folder. Preserve original private masters and test undo, label protection and stale correction rejection.

SVG geometry checks cover explicitly semantic linear elements and rectangular fixtures. Unsupported elements and incomplete calibration must remain visible. Never represent a software check as architectural, load-bearing or as-built certification. Hosted ChatGPT follow-up is conditional on a supported host bridge; no direct Project API or deployed backend exists.
